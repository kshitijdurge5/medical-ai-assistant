# 🩺 Medical AI Assistant

An AI-powered medical education assistant built with Python and the DeepSeek API.

This project demonstrates how to build a practical AI application using an LLM API, prompt engineering, environment variables, error handling, and Python.

## 🚀 Features

- Ask medical and health-related educational questions
- Uses the DeepSeek LLM API
- Interactive command-line interface
- Custom system prompt for medical education
- Secure API-key loading through environment variables
- Error handling for failed API requests
- Clear AI-generated responses

## 🧠 Technologies Used

- Python
- DeepSeek API
- OpenAI Python SDK
- python-dotenv
- LLM API concepts
- Prompt Engineering
- Environment Variables
- Git & GitHub

```text
